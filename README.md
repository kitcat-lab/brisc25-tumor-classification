# BRISC 2025 - Brain Tumor MRI Classification

Training scripts, feature extraction pipelines, result files, and forensic audit logs for the BRISC 2025 brain tumor MRI classification study.

## Overview

This repository supports the article:

> C. Bota, M. I. Barbosa, P. M. Rodrigues, "Which Brain-Tumor Classifier Really Wins? A Leakage-Controlled
Benchmark on BRISC 2025"

The study compares wavelet-texture (GLCM) classifiers, transfer-learning backbones (ResNet50, VGG16, EfficientNet-B2, ConvNeXt-Tiny), and a scratch CNN on the BRISC 2025 dataset across three imaging planes (axial, coronal, sagittal).

## Repository structure

```
inputs/          Wavelet feature matrices (Excel, generated by MATLAB scripts)
outputs/         Model results: metrics, predictions, confusion matrices, Grad-CAM, SHAP
images/          Figures used in the article and supplementary comparisons
workers/
  matlab/        GLCM + DWT feature extraction scripts (bior1.1, db4, skull stripping)
  notebooks/     Training, evaluation, and figure-generation notebooks (Colab/Jupyter)
  python/        Figure and table builders, environment setup
guis/            PyQt6 demo classifier application
topmodels/       Model registry metadata
```

## Reproducing

### Feature extraction (MATLAB)

1. Place the BRISC 2025 `classification_task/` images in the MATLAB working directory.
2. Run `workers/matlab/batch_pre_processed_brisc25_clean.m` (without skull stripping) or `batch_pre_processed_brisc25_clean_skullstrip.m` (with skull stripping).
3. Output Excel files go to `inputs/`.

### CNN training (Python)

1. Install dependencies: `pip install -r workers/requirements_figures.txt`
2. Open the relevant notebook in `workers/notebooks/` (e.g., `workflow16_scratch_cnn_optimized.ipynb` for the scratch CNN).
3. Notebooks expect the BRISC 2025 dataset and the feature Excel files from the previous step.

### Figure generation

```bash
cd workers && python python/build_all_figures.py
```
